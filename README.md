# Despachos Acuña

App web instalable (PWA) para el control de despachos de Maestranza Acuña: carga de camiones contra el listado de conjuntos, glosa para la guía de despacho, entradas desde galvanizado, recepción en obra y avance por obra.

- Datos y usuarios en Supabase, protegidos por inicio de sesión y reglas por rol. Este repositorio no contiene datos de obras.
- Sin compilación: HTML, CSS y JavaScript servidos tal cual por GitHub Pages.
